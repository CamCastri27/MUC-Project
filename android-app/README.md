# Haptic Glove — Android app

Android app that controls the 5 motors on the PHR 25 haptic glove over Bluetooth LE.

See the [main README](../README.md) for:

- [Opening the test environment (emulator)](../README.md#open-the-test-environment-emulator)
- [Connecting to the glove](../README.md#connect-to-the-glove)
- [Where to change things](../README.md#where-to-change-things)

Quick start on macOS:

```bash
./scripts/setup_test_env.sh   # one time
./scripts/run_emulator.sh     # emulator (turn on Demo in the app)
./scripts/run_emulator.sh --device   # USB-connected phone
```
